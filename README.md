# Proyecto Red Metropolitana de Transporte

## Ciencia de Datos
Universidad Rafael Landívar  
Segundo Semestre 2026

## Descripción

Este proyecto desarrolla una arquitectura de datos para integrar información proveniente de cuatro sistemas de transporte del área metropolitana de Guatemala: Transmetro, Transurbano, MetroRiel y Aerómetro.

La arquitectura permitirá ingerir, almacenar, transformar, validar e integrar los datos para posteriormente realizar análisis de movilidad y visualización en Tableau.

## Arquitectura general

Fuentes → Ingesta → Bronze → Silver → Gold → Tableau

También se contempla una capa de cuarentena para registros inválidos y una capa de features para futuros modelos de ciencia de datos.
